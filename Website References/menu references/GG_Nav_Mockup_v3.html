Claude Code — Shopify Liquid Conversion Notes

Shopify Liquid Conversion Notes

  • 01Save as sections/header.liquid. Load all 3 fonts via assets/fonts.css or link Google Fonts in layout/theme.liquid.
  • 02Font stack: font-family: 'Bebas Neue' for logo/badge, 'Archivo Narrow' for nav links and body, 'Barlow Condensed' for CTAs and badges only.
  • 03Nav links: {% for link in section.settings.menu.links %}. Use link.links.size > 0 to conditionally render mega menu vs simple dropdown vs plain link.
  • 04Announcement bar: schema repeatable block, max 6 messages, each with a short text field. Duplicate the track div in HTML for seamless CSS loop.
  • 05Featured product cards: bind to section.settings.mega_featured_collection, loop first 2 products, use product.featured_image | image_url: width: 400 in place of SVG placeholders.
  • 06Cart count: {{ cart.item_count }}. Toggle visibility with {% if cart.item_count == 0 %}style="display:none"{% endif %}.
  • 07Sticky nav: JS scroll listener adds .is-sticky at scrollY > 0. Sticky state: position:fixed; top:0; backdrop-filter:blur(10px); background:rgba(17,17,17,0.92).
  • 08Mobile drawer: <details>/<summary> for accordion — zero JS for open/close. Add CSS details[open] summary .mob-chev to rotate chevron.
  • 09"Sale" colour: {% if link.title == 'Sale' %}class="nav-link sale"{% else %}class="nav-link"{% endif %}.
  • 10Mega menu hover: CSS-only via .nav-item:hover .mega-menu. Use visibility + opacity transition — never display:none — so CSS transitions fire correctly.
  • 11SVG icons in mega menu: extract to snippets/icon-[name].liquid and include via {% render 'icon-rack' %} for reuse across the theme.
  • 12All skewed shapes use clip-path: polygon() Performance Skew motif — do not replace with border-radius.
