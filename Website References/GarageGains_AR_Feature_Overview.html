Feature Brief

Shopify AR
Feature Overview

GarageGains  ·  Product Page Enhancement  ·  April 2026

This document outlines how Augmented Reality (AR) can be added to GarageGains product pages, allowing customers to visualise gym equipment in their own home gym via smartphone — no app download required.
1

How Shopify AR Works

iOS (iPhone / iPad)

Customer taps "View in AR" on the product page. Apple's native Quick Look AR viewer launches — places the equipment in the room using the camera.

.usdz model required
Android

Opens Google Scene Viewer AR directly in the browser. Same experience — no app install required for the customer.

.glb model required
Powered by: Google's <model-viewer> web component — already bundled inside the Dawn base theme GarageGains is built on. No third-party app or monthly subscription needed.
2

What's Required

  1. 3D model files for each product — a .glb file (Android) and/or .usdz file (iOS). This is the main prerequisite. See Section 3 for sourcing options.

  2. Upload to Shopify — add the 3D model as product media (same workflow as uploading images). Shopify automatically detects the file type and flags it as a 3D model.

  3. Liquid code on the PDP — the AR viewer panel is wired into gg-product-main.liquid. Claude Code handles all of this once a model file is available.

3

Sourcing 3D Model Files

Method How It Works Cost Quality
Commission a 3D artist Provide product photos/dimensions; artist delivers .glb + .usdz files $50–$200 / product Best — production-grade
Photogrammetry (Capture app / Matterport) Photograph the real product from multiple angles; software auto-generates a 3D model Free – $50 Good for solid objects
AI-to-3D (Luma AI / Meshy.ai) Upload photos; AI generates a 3D mesh automatically Free tier available Variable — test first
Morgan Sports catalogue Ask the supplier directly — some wholesalers provide 3D assets for retail partners Likely free Official, accurate
4

What Claude Code Will Build

  • AR viewer panel embedded in the product page that activates automatically when a 3D model is attached to the product
  • Device detection — shows the correct AR button for iOS (Quick Look) vs Android (Scene Viewer) vs desktop (3D rotate-only view)
  • Graceful fallback — if no 3D model is uploaded, the section renders a standard product image with no broken UI
  • Styled AR launch button using the GarageGains skewed parallelogram button aesthetic
  • No third-party apps, no monthly subscription — uses Shopify's native model-viewer component
5

The Key Constraint

3D Models Must Be Sourced Externally

Claude Code can write all the Liquid, JavaScript, and CSS required for the AR feature. The one thing it cannot do is generate the 3D model files themselves — those need to come from a 3D artist, a photogrammetry scan, an AI-to-3D service, or the Morgan Sports supplier catalogue. Once a single .glb file exists, the complete AR feature can be built and tested live on the GarageGains product page immediately.

Recommended Next Steps

  1. Contact Morgan Sports — ask if 3D model assets (.glb / .usdz) are available for any products in their wholesale catalogue. This is the fastest and most accurate path.

  2. Choose a sourcing method — if Morgan Sports don't supply models, pick between Luma AI (free, test quality first) or commissioning a 3D artist for flagship products.

  3. Provide one .glb file to Claude Code — the full AR viewer will be built and deployed to the GarageGains PDP immediately, ready for testing on a real device.
